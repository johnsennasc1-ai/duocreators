# Duo Creators

Site portfólio da Duo Creators (design e social media), em um único arquivo `index.html`.

- Paleta: laranja, preto e bege claro
- Página inicial com serviços, sobre e contato
- Subpágina de portfólio (`#portfolio-completo`) com 36 trabalhos e visualização ampliada

Para publicar: GitHub Pages (Settings > Pages > branch `main`, pasta `/ (root)`).
